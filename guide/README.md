stronger memory\n- **Interleaving**: Mix game types → prevents cognitive plateau\n- **Retrieval practice**: Each game is retrieval in a new context\n- **Gamification**: Points, streaks, achievements → dopamine loop\n\n### For Engagement (Duolingo's Secret)\n- Users have **choice** (pick your game)\n- Each game **feels different** (low boredom)\n- Quick **feedback loops** (instant results)\n- **Progress visibility** (XP, achievements, leaderboards)\n\n### For Scale (Technical)\n- Single `gameTypeEngine` → consistent progression\n- Component templates → rapid new game development\n-
